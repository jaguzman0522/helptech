Frontend SuperAdmin: Control Maestro de la Infraestructura
1. Alcance y Responsabilidades
El SuperAdmin tiene una visión consolidada de todas las empresas registradas. Sus acciones afectan directamente el comportamiento de los portales de clientes.

A. Gestión de Empresas (Clientes)
Aprobación/Activación: Validar empresas recién registradas.
Suspensión: Bloquear el acceso a una empresa completa (por falta de pago o violación de términos).
Monitoreo MRR: Ver los ingresos mensuales recurrentes generados por cada cliente y el total global.
Alertas de Expiración: Identificar empresas cuyos planes de prueba (trial) están por vencer.
B. Diseño de Planes y Monetización (Matrix de Funciones)
Este es el punto más crítico. El SuperAdmin define qué "ve" el cliente final:

Activación de Módulos: Puede activar o desactivar módulos enteros (IA, Inventario, Logística, API Externa) por cada plan (Free, Pro, Enterprise).
Límites de Uso: Define cuántos usuarios y cuántos tickets puede crear una empresa según su nivel de suscripción.
Conexión con Stripe: Asocia los IDs de precios de Stripe con los niveles del sistema para automatizar el cobro.
C. Sistema de Promociones y "Gift Features"
Códigos de Descuento: Crear cupones para el registro.
Desbloqueo Temporal: Crear códigos que activan funciones premium (como la IA) por una cantidad X de días a empresas en planes gratuitos.
2. Implementación Técnica
Estructura de Navegación
Las rutas están aisladas en app/(superadmin)/superadmin/, protegidas por un middleware que valida el rol SuperAdmin o Staff global.

Dashboard Global: Gráficos de distribución de planes (usando recharts), ingresos estimados y alertas de control.
Gestión de Niveles: Una matriz donde se marcan checks en los módulos permitidos. Si el SuperAdmin desmarca "Inventario" en el Plan FREE, el botón desaparece automáticamente del menú de miles de empresas.
Comunicación Global (Broadcast)
El SuperAdmin tiene una herramienta de Broadcast (vía Pusher). Al enviar un comunicado:

Se inserta en la tabla Notificacion para todos los usuarios.
Se dispara un evento WebSocket que muestra un banner de alerta en tiempo real en todos los portales activos del sistema.
3. Impacto en el Portal de Clientes
Cada acción del SuperAdmin tiene un efecto en cascada:

En la UI del Cliente: El componente Sidebar y las rutas del cliente consultan los permisos del Plan asignado por el SuperAdmin. Si el plan no tiene el módulo ia, el frontend no renderiza esas opciones.
En el Backend (API): Los middlewares de cada empresa validan los límites impuestos por el SuperAdmin. Si el límite es de 100 tickets y la empresa intenta crear el 101, el backend devuelve un error de "Límite excedido, por favor mejore su plan".
Estado de Cuenta: Si el SuperAdmin marca una empresa como suspendida: true, el middleware de autenticación bloquea cualquier sesión activa de esa empresa de forma inmediata.
4. Manejo de Datos y Auditoría
Portal de Auditoría: El SuperAdmin puede ver los logs de errores de todas las empresas (ErrorLog) para detectar fallos técnicos antes de que el cliente los reporte.
Gestión de Staff: El SuperAdmin puede crear otros usuarios de "Staff" para soporte técnico interno, con permisos limitados dentro de la consola global.
IMPORTANT

El SuperAdmin no maneja tickets individuales de las empresas, a menos que sea para soporte técnico del sistema en sí. Su enfoque es comercial y de infraestructura.

  const [empresas, setEmpresas] = useState<any[]>([]);
  const [planes, setPlanes] = useState<any[]>([]);
  const [loading, setLoading] = useState(true);
  const [isModalOpen, setIsModalOpen] = useState(false);
  const [isSubmitting, setIsSubmitting] = useState(false);
  const [editingId, setEditingId] = useState<number | null>(null);
  
  const [formData, setFormData] = useState({
    nombre: '',
    slug: '',
    planId: '',
    fechaExpiracion: ''
  });

  const fetchData = async () => {
    setLoading(true);
    try {
      const [resEmp, resPlanes] = await Promise.all([
        fetch('/api/superadmin/empresas'),
        fetch('/api/superadmin/planes')
      ]);
      const dataEmp = await resEmp.json();
      const dataPlanes = await resPlanes.json();
      setEmpresas(dataEmp);
      setPlanes(dataPlanes);
    } catch (error) {
      toast.error('Error al cargar datos');
    } finally {
      setLoading(false);
    }
  };

  useEffect(() => {
    fetchData();
  }, []);

  const handleEdit = (empresa: any) => {
    setEditingId(empresa.id);
    setFormData({
      nombre: empresa.nombre,
      slug: empresa.slug,
      planId: empresa.planId?.toString() || '',
      fechaExpiracion: empresa.fechaExpiracion ? new Date(empresa.fechaExpiracion).toISOString().split('T')[0] : ''
    });
    setIsModalOpen(true);
  };

  const handleToggleSuspension = async (empresa: any) => {
    const nuevoEstado = !empresa.suspendido;
    const confirmacion = confirm(`¿Estás seguro de ${nuevoEstado ? 'SUSPENDER' : 'ACTIVAR'} a ${empresa.nombre}?`);
    if (!confirmacion) return;

    try {
      const res = await fetch(`/api/superadmin/empresas/${empresa.id}`, {
        method: 'PATCH',
        headers: { 'Content-Type': 'application/json' },
        body: JSON.stringify({ 
          suspendido: nuevoEstado,
          motivoSuspension: nuevoEstado ? 'Suspensión manual por administrador' : ''
        })
      });

      if (res.ok) {
        toast.success(nuevoEstado ? 'Cliente suspendido' : 'Cliente reactivado');
        fetchData();
      }
    } catch (error) {
      toast.error('Error de red');
    }
  };

  const handleSubmit = async (e: React.FormEvent) => {
    e.preventDefault();
    setIsSubmitting(true);
    try {
      const url = editingId ? `/api/superadmin/empresas/${editingId}` : '/api/superadmin/empresas';
      const method = editingId ? 'PATCH' : 'POST';

      const res = await fetch(url, {
        method,
        headers: { 'Content-Type': 'application/json' },
        body: JSON.stringify({
          ...formData,
          planId: parseInt(formData.planId),
          fechaExpiracion: formData.fechaExpiracion ? new Date(formData.fechaExpiracion) : null
        })
      });

      if (res.ok) {
        toast.success(editingId ? 'Datos actualizados' : 'Empresa creada correctamente');
        setIsModalOpen(false);
        setEditingId(null);
        fetchData();
      } else {
        const err = await res.json();
        toast.error(err.message || 'Error en la operación');
      }
    } catch (error) {
      toast.error('Error de red');
    } finally {
      setIsSubmitting(false);
    }
  };

  return (
    <div className="space-y-8 animate-in fade-in duration-500 pb-20">
      <div className="flex flex-col md:flex-row justify-between items-start md:items-center gap-4">
        <div>
          <h1 className="text-4xl font-black text-slate-900 tracking-tight">Administración Global</h1>
          <p className="text-slate-500 font-medium">Gestión de clientes, suscripciones y estados de vigencia.</p>
        </div>
        <button 
          onClick={() => {
            setEditingId(null);
            setFormData({ nombre: '', slug: '', planId: planes[0]?.id.toString() || '', fechaExpiracion: '' });
            setIsModalOpen(true);
          }}
          className="px-6 py-3 bg-slate-900 text-white rounded-2xl font-bold flex items-center gap-2 hover:bg-slate-800 active:scale-95 transition-all shadow-lg"
        >
          <Plus size={20} /> Registrar Cliente
        </button>
      </div>

      <div className="grid grid-cols-1 md:grid-cols-4 gap-6">
        {[
          { label: 'Total Clientes', value: empresas.length, icon: Building2, color: 'text-blue-600', bg: 'bg-blue-50' },
          { label: 'Suspendidos', value: empresas.filter(e => e.suspendido).length, icon: Ban, color: 'text-red-600', bg: 'bg-red-50' },
          { label: 'Próximos a Vencer', value: empresas.filter(e => e.fechaExpiracion && new Date(e.fechaExpiracion) < new Date(Date.now() + 7 * 24 * 60 * 60 * 1000)).length, icon: AlertTriangle, color: 'text-amber-600', bg: 'bg-amber-50' },

      setLoading(false);
    }

      ...prev,
      [id]: { ...prev[id], ...updates }

       toast.error('Error al crear');

                    {newPromo.funcionesActivadas.includes(modulo.id) ? <CheckCircle2 size={18} /> : <Zap size={18} className="opacity-30" />}
                  </button>
                ))}
              </div>
              <button 
                type="submit"
                className="w-full py-5 bg-blue-600 text-white rounded-[24px] font-black text-lg hover:bg-blue-700 transition-all shadow-xl shadow-blue-100"
              >
                Crear Promoción
              </button>
            </div>
          </form>
        </Card>
      )}

      {/* Lista de Promociones */}
      <div className="grid grid-cols-1 md:grid-cols-2 lg:grid-cols-3 gap-6">
        {loading ? (
           <div className="col-span-full py-20 text-center"><Activity className="animate-spin mx-auto text-blue-200" size={40} /></div>
        ) : promos.map((promo) => (
          <Card key={promo.id} className="p-8 border-none shadow-xl rounded-[40px] bg-white group hover:shadow-2xl transition-all relative overflow-hidden">
             <div className="relative z-10">
                <div className="flex justify-between items-start mb-4">
                   <div className="px-3 py-1 bg-amber-50 text-amber-600 rounded-lg text-[10px] font-black uppercase tracking-widest">
                      {promo.activo ? 'Activo' : 'Inactivo'}
                   </div>
                   <button className="text-slate-300 hover:text-red-500 transition-colors">
                      <Trash2 size={18} />
                   </button>
                </div>
                <h3 className="text-3xl font-black text-slate-900 mb-2">{promo.codigo}</h3>
                <p className="text-sm font-bold text-slate-500 mb-6">
                   {promo.tipo === 'PORCENTAJE' ? `${promo.descuento}% de descuento` : `$${promo.descuento} de descuento`}
                </p>
                
                <div className="space-y-3 mb-6">
                   <p className="text-[10px] font-black text-slate-400 uppercase tracking-widest">Módulos de regalo:</p>
                   <div className="flex flex-wrap gap-2">
                      {Array.isArray(promo.funcionesActivadas) && promo.funcionesActivadas.map((f: string) => (
                        <span key={f} className="px-2 py-1 bg-blue-50 text-blue-600 rounded-md text-[9px] font-black uppercase">
                           {f}
                        </span>
                      ))}
                      {(!promo.funcionesActivadas || promo.funcionesActivadas.length === 0) && (
                        <span className="text-[10px] text-slate-300 italic">Sin funciones extras</span>
                      )}
                   </div>
                </div>

                <div className="flex items-center justify-between text-xs font-bold pt-4 border-t border-slate-50">
                   <div className="flex items-center gap-2 text-slate-400">
                      <Calendar size={14} /> {new Date(promo.validoHasta).toLocaleDateString()}
                   </div>
                   <div className="text-slate-700">
                      {promo.usosActuales} / {promo.limiteUsos === 0 ? '∞' : promo.limiteUsos} usos
                   </div>
                </div>
             </div>
             {/* Background Decoration */}
             <div className="absolute -right-8 -bottom-8 w-32 h-32 bg-slate-50 rounded-full group-hover:scale-150 transition-transform duration-700" />
          </Card>
        ))}
      </div>
    </div>
  );
}

API Dashboard: 

api/superadmin/dashboard/route.ts

import { NextResponse } from 'next/server';
import { getServerSession } from 'next-auth';
import { authOptions } from '@/lib/auth';
import prisma from '@/lib/prisma';

export async function GET() {
  try {
    const session = await getServerSession(authOptions);
    if (!session || !session.user.role?.toLowerCase().includes('super')) {
      return NextResponse.json({ message: 'No autorizado' }, { status: 403 });
    }

    const startOfMonth = new Date();
    startOfMonth.setDate(1);
    startOfMonth.setHours(0, 0, 0, 0);

    const [
      totalEmpresas,
      empresasEsteMes,
      empresasRecientes,
      porExpirar,
      suspendidas,
      planes,
      suscripcionesActivas
    ] = await Promise.all([
      prisma.empresa.count(),
      prisma.empresa.count({ where: { createdAt: { gte: startOfMonth } } }),
      prisma.empresa.findMany({
        take: 6,
        orderBy: { createdAt: 'desc' },
        include: { plan: true }
      }),
      prisma.empresa.count({
        where: {
          fechaExpiracion: {
            lt: new Date(Date.now() + 7 * 24 * 60 * 60 * 1000) // 7 días
          }
        }
      }),
      prisma.empresa.count({
        where: { suspendido: true }
      }),
      prisma.plan.findMany({
        include: {
          _count: {
            select: { empresas: true }
          }
        }
      }),
      prisma.empresa.count({ 
        where: { 
          activo: true, 
          planId: { not: null } 
        } 
      })
    ]);

    // Calcular MRR (Ingresos Mensuales Recurrentes)
    const ingresosMensuales = planes.reduce((acc, p) => acc + (p._count.empresas * p.precio), 0);
    
    // Calcular Crecimiento (Empresas nuevas este mes vs total previo)
    const totalPrevio = totalEmpresas - empresasEsteMes;
    const crecimientoMensual = totalPrevio > 0 
      ? Math.round((empresasEsteMes / totalPrevio) * 100) 
      : (empresasEsteMes > 0 ? 100 : 0);

    const stats = {
      global: {
        empresas: totalEmpresas,
        ingresosMensuales: ingresosMensuales.toLocaleString(),
        suscripcionesActivas,
        crecimientoMensual
      },
      alertas: {
        porExpirar,
        suspendidas
      },
      actividad: {
        empresasRecientes
      },
      distribucionPlanes: planes.map(p => ({
        nombre: p.nombre,
        cantidad: p._count.empresas,
        ingresos: (p._count.empresas * p.precio).toLocaleString()
      }))
    };

    return NextResponse.json(stats);
  } catch (error) {
    console.error("Error en Dashboard API:", error);
    return NextResponse.json({ message: 'Error al obtener dashboard' }, { status: 500 });
  }
}

API Planes: 

api/superadmin/planes/route.ts

import { NextResponse } from 'next/server';
import { getServerSession } from 'next-auth';
import { authOptions } from '@/lib/auth';
import prisma from '@/lib/prisma';

export async function GET() {
  try {
    const session = await getServerSession(authOptions);
    if (!session) {
      return NextResponse.json({ message: 'No autorizado' }, { status: 401 });
    }

    const planes = await prisma.plan.findMany({
      orderBy: { precio: 'asc' },
      include: {
        _count: {
          select: { empresas: true }
        }
      }
    });

    return NextResponse.json(planes);
  } catch (error) {
    return NextResponse.json({ message: 'Error al obtener planes' }, { status: 500 });
  }
}

export async function POST(req: Request) {
  try {
    const session = await getServerSession(authOptions);
    if (!session || !session.user.role?.toLowerCase().includes('super')) {
      return NextResponse.json({ message: 'No autorizado' }, { status: 403 });
    }

    const body = await req.json();
    const { nombre, descripcion, precio, funciones, limites, intervalo, moneda, stripePriceId } = body;

    if (!nombre) {
      return NextResponse.json({ message: 'El nombre es requerido' }, { status: 400 });
    }

    const plan = await prisma.plan.create({
      data: {
        nombre,
        descripcion,
        precio: parseFloat(precio) || 0,
        intervalo: intervalo || 'mensual',
        moneda: moneda || 'USD',
        stripePriceId,
        funciones: funciones || [],
        limites: limites || {}
      }
    });

    return NextResponse.json(plan, { status: 201 });
  } catch (error: any) {
    if (error.code === 'P2002') {
      return NextResponse.json({ message: 'Ya existe un plan con ese nombre' }, { status: 400 });
    }
    return NextResponse.json({ message: 'Error al crear plan' }, { status: 500 });
  }
}

export async function PATCH(req: Request) {
  try {
    const session = await getServerSession(authOptions);
    if (!session || !session.user.role?.toLowerCase().includes('super')) {
      return NextResponse.json({ message: 'No autorizado' }, { status: 403 });
    }

    const body = await req.json();
    const { id, nombre, descripcion, precio, funciones, limites, intervalo, moneda, stripePriceId, activo } = body;

    if (!id) {
      return NextResponse.json({ message: 'El ID del plan es requerido' }, { status: 400 });
    }

    const plan = await prisma.plan.update({
      where: { id: parseInt(id) },
      data: {
        nombre,
        descripcion,
        precio: precio !== undefined ? parseFloat(precio) : undefined,
        intervalo,
        moneda,
        stripePriceId,
        funciones,
        limites,
        activo
      }
    });

    return NextResponse.json(plan);
  } catch (error) {
    return NextResponse.json({ message: 'Error al actualizar plan' }, { status: 500 });
  }
}
